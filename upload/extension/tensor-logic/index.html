🔢 Tensor Logic API

ATen & nn inspired tensor operations and neural networks for OpenCart

Version 1.0.0 | Powered by tensor-logic.org

Overview

Tensor Logic brings powerful tensor operations and neural network capabilities to OpenCart. Inspired by PyTorch's ATen (A Tensor Library) and nn (Neural Network) modules, this extension provides a PHP-based implementation for machine learning inference in e-commerce applications.

🎯 Tensor Operations

  • Multi-dimensional arrays
  • Element-wise operations
  • Matrix multiplication
  • Reductions & aggregations

🧠 Neural Networks

  • Dense (FC) layers
  • Multiple activations
  • Sequential models
  • Serialization support

🚀 E-commerce Ready

  • Product recommendations
  • Dynamic pricing
  • Customer segmentation
  • Sales prediction

🔌 REST API

  • JSON-based endpoints
  • Easy integration
  • Error handling
  • Comprehensive docs

API Endpoints

All endpoints are relative to: /index.php?route=extension/tensor_logic/api/tensor_logic

GET API Information

URL: /index.php?route=extension/tensor_logic/api/tensor_logic

Returns API version, available endpoints, and documentation links.

curl http://localhost/index.php?route=extension/tensor_logic/api/tensor_logic

POST Create Tensor

URL: .create

Create a tensor from nested array data.

curl -X POST http://localhost/index.php?route=extension/tensor_logic/api/tensor_logic.create \
  -H "Content-Type: application/json" \
  -d '{"data": [[1, 2], [3, 4]]}'

POST Add Tensors

URL: .add

Element-wise addition of two tensors.

curl -X POST http://localhost/index.php?route=extension/tensor_logic/api/tensor_logic.add \
  -H "Content-Type: application/json" \
  -d '{"a": [[1, 2]], "b": [[3, 4]]}'

POST Multiply Tensors

URL: .multiply

Element-wise multiplication of two tensors.

curl -X POST http://localhost/index.php?route=extension/tensor_logic/api/tensor_logic.multiply \
  -H "Content-Type: application/json" \
  -d '{"a": [[1, 2]], "b": [[3, 4]]}'

POST Matrix Multiplication

URL: .matmul

Matrix multiplication (dot product) of two 2D tensors.

curl -X POST http://localhost/index.php?route=extension/tensor_logic/api/tensor_logic.matmul \
  -H "Content-Type: application/json" \
  -d '{"a": [[1, 2], [3, 4]], "b": [[5, 6], [7, 8]]}'

GET Create Model

URL: .createModel

Create an example neural network model with specified architecture.

curl "http://localhost/index.php?route=extension/tensor_logic/api/tensor_logic.createModel?input_size=3&hidden_size=5&output_size=2"

POST Neural Network Prediction

URL: .predict

Run inference on a neural network model.

curl -X POST http://localhost/index.php?route=extension/tensor_logic/api/tensor_logic.predict \
  -H "Content-Type: application/json" \
  -d '{
    "model": {
      "version": "1.0",
      "layers": [...]
    },
    "input": [1.0, 2.0, 3.0]
  }'
